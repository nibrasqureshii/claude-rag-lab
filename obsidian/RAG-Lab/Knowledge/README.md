# Knowledge

This folder is where you would author new knowledge base articles in
human-friendly Markdown, the same way the real source documents in the
project's `knowledge/` folder are written.

Obsidian is **not** the vector database — it's the authoring layer. Once
you're happy with a document here, copy it into the project's `knowledge/`
folder and click **Re-index** in the app's Knowledge Base tab to make it
searchable. See [[RAG]] in Concepts for why that separation exists.
