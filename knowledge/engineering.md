# Acme Software Co. — Engineering Practices

> **Fictional company.** These practices are invented examples for this RAG
> teaching demo.

## Deployment Practices

Acme deploys to managed cloud platforms with infrastructure as code and
CI/CD pipelines, so every release is repeatable and auditable.

## Code Review

Every change is peer-reviewed before merge, and pull requests must include
tests for new behavior.

## AI Feature Practices

AI features follow four stages: discovery, prototype with an evaluation set,
integration behind a feature flag, and production monitoring of answer
quality.

## Discovery-First Approach

Engineering work follows a short Technical Advisory phase that defines
scope and success criteria before implementation begins.
